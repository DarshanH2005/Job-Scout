# Job Scout

Job Scout is a private Windows web app for scanning company career feeds, saving openings, and tracking referral conversations.

## Start

Open **Launch Job Scout.cmd**. It installs the Python dependencies on the first run and opens [Job Scout on this computer](http://127.0.0.1:8765/). Keep the server window open while using the app. Press Ctrl+C there to stop it. If the browser stays closed, open the link above. The launcher uses uv when installed and otherwise needs Python 3.11 or newer.

The SQLite file is stored at **%LOCALAPPDATA%\JobScout\scout.sqlite3**. Close the app before copying it for backup. The source folder can be moved without moving your database.

## Find jobs and ask for referrals

1. Click **Find latest jobs**, or type it in **Commands** (Ctrl+K). The watchlist starts with 200 companies. It includes 168 automated sources across Greenhouse, Lever, Ashby, SmartRecruiters, and Workday. The other 32 have careers-page links and a **Manual source** status. If feeds fail, **Retry failed feeds** checks just those sources. The coverage panel keeps the latest full scan separate.
2. Filter by location, experience, or posting age, or search by role or company. **Explicit early-career roles** shows listings whose title signals entry level, such as new grad, junior, or intern. The 7- and 30-day filters use the selected employer-posted or first-seen date. Later scans identify listings first observed on a previously checked board; new matches appear ahead of older matches within each location group. Transient feed errors are retried once when appropriate.
3. Review a role, check location and eligibility evidence, and open the direct application link. Optionally save your expected graduation year in **Settings**; Job Scout flags some postings that explicitly mention a different year and shows the employer’s wording. The warning is not an eligibility decision and may miss ambiguous requirements. **Check this posting** looks for that role on its employer feed. When an employer supplies a deadline, Job Scout shows it separately from your own target application date. **Saved jobs** puts outstanding roles with target dates first, earliest first. Use **Hide from job feed** to clear a role from your feed, then open **Hidden jobs** to restore it.
4. Use **Find people** or **Add someone I know**. Existing referral drafts and conversations appear on the job itself. Review the contact, save their email on a Gmail referral, and choose **Send via Gmail**. Job Scout sends the draft, records the send, and links the thread for reply checks. For LinkedIn and community outreach, send in the original service and choose **Record as sent**. Mark the application separately.
5. Reopen **Referrals** to see the oldest due conversations first. Each referral shows the posting, any contact source, and a LinkedIn handoff where applicable. Use **Add conversation link** to save the exact message thread for later. While waiting for a reply, you can save or copy an editable follow-up. Record the send to keep its text in history and schedule the next check. A reply clears that reminder. The inbox distinguishes a referral offer from confirmation it was submitted.
   **Send Gmail follow-up** uses the linked thread and checks it for a reply before sending. To send later, review the message and choose **Schedule a Gmail follow-up**. Job Scout checks for a reply before sending the saved message at the chosen time, or when the app next opens. You can cancel from the conversation. If Gmail’s send outcome is unclear, check Sent and use the manual record action only after confirming delivery.
6. The job feed’s **Next actions** panel shows up to three due application targets and three referrals that need attention, with a shortcut to each record.

The source registry and status checks took inspiration from [job-alerts](https://github.com/SirFuzzyWalls/job-alerts). The application reads employer feeds directly. [Greenhouse](https://docs.greenhouse.io/job-board.html) · [Lever](https://github.com/lever/postings-api) · [Ashby](https://developers.ashbyhq.com/docs/public-job-posting-api) · [SmartRecruiters](https://developers.smartrecruiters.com/docs/endpoints). Workday support uses the public endpoint used by its career sites, as described by [career-ops](https://github.com/career-ops-hq/career-ops/blob/main/docs/SUPPORTED_JOB_BOARDS.md). It rejects capped or incomplete snapshots; the employer's relative dates are not converted into exact posting dates. Each scan resolves up to 20 early-career listings per employer when the feed only gives a location count. If a detail cannot be loaded, the location stays unclear; open the role to try again.

## Optional integrations

Configure Brave and Google in **Settings**. Job Scout stores those credentials in Windows Credential Manager. The environment variables in **.env.example** are also supported and require a restart when edited.

- **Public contact research.** Save a [Brave Search API key](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started) in Settings. Searches use the company and job specialty. Without a key, the app returns saved contacts and a LinkedIn search query. It also checks public engineering author pages for Stripe and Cloudflare, a recent conference speaker list for Datadog, and Affirm’s public tech-blog feed for named authors and teams. Confirm each person’s current employment and location.
- **Gmail.** In your Google Cloud project, enable Gmail API, configure the consent screen and your test user if applicable, and create a **Desktop app** OAuth client. Open Job Scout at **127.0.0.1:8765**, choose the downloaded JSON in Settings, then click **Connect Gmail for sending and replies**. The app requests `gmail.send` and `gmail.metadata`. For reply checks alone, choose **Connect for replies only**. If Gmail is already connected for replies, use **Enable Gmail sending**. When Google authorization expires, use **Reconnect Gmail** in Settings and select the same account. [Google OAuth setup](https://developers.google.com/identity/protocols/oauth2/native-app)
- **Link Gmail conversations.** In Gmail, label a sent thread **Job Scout**. Save the contact’s email, record the send in the app with Gmail as its channel, then select **Link Gmail thread** and choose the labeled conversation. Its single recipient must match the saved email, with no extra Cc or Bcc recipients. Job Scout reads the linked thread’s metadata and looks for replies from that recipient. Checks run every ten minutes while the app is open and on demand. Automated messages and delivery failures can require manual review.
- **LinkedIn email hints.** Optionally enable message notification emails in LinkedIn. Create a Gmail filter that applies **Job Scout LinkedIn** to those notification emails, then turn on hints in Job Scout Settings. Hints are reminders to check LinkedIn and never confirm a reply or change a conversation by themselves.
- **Draft rewrite.** Set **SCOUT_OPENAI_KEY** and **SCOUT_OPENAI_MODEL** to enable **AI rewrite**. Clicking it sends the draft text to the configured API and may incur model charges. Job scans, templates, and reply checks run without model calls.

## Developer checks

From this folder, run **python -m pytest -q** with the runtime requirements and pytest installed. Set **SCOUT_DB** to a different SQLite path to use an isolated workspace.
